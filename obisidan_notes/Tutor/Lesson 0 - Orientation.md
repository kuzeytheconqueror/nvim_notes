# Lesson 0 · Orientation

> [!abstract] Goal
> Understand how `:Tutor` works before touching any real command.

## How the tutor talks to you

> [!info] Nothing you do here is saved
> The lessons modify the text, but the changes are never written to disk.
> Mess up as much as you like. `<Esc>` then `u` undoes the latest change.

| Symbol | Meaning |
|:------:|---------|
| ✗ | A line you are expected to fix |
| ✓ | The line is correct now |
| `:help` | A command you type after pressing `:` |
| `<Enter>`, `<Esc>` | A **key** to press, not text to type |

## Inside the tutor

- Press `<Enter>` on a link to open the linked help section.
- Press `K` on any word to jump to its documentation.
- Close a help window with `:q` `<Enter>`.

> [!tip] Scrolling
> Hold `j` to move down. That is already the first Neovim command you know.
